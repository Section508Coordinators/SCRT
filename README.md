# SCRT 5.2.0
# Project Title
**Section 508 Compliance Reporting Tool (SCRT)** 

SCRT is a standalone, browser-based tool for recording Section 508 test results. It stores data locally on the user’s device in JSON and/or HTML file formats. These files may be shared as needed, and JSON data can be further processed for approved analytics and reporting purposes.


## Getting Started
1.	Download the SCRT files from the repository to your local device. Downloads are typically saved to your Downloads folder by default. 
2.	On the repository’s [main page](https://github.com/Section508Coordinators/SCRT), select Code, then select Download ZIP.
3.	After the download is complete, extract the ZIP file to a local folder.
4.	Open index.html from the extracted folder.  
5.	For detailed guidance, refer to the [SCRT Training Manual](https://github.com/Section508Coordinators/SCRT/blob/master/Resources/SCRTTrainingManual.pdf) in the Resources folder.
6.	You can also Try SCRT [Here](https://section508coordinators.github.io/SCRT/) to launch the tool directly without downloading locally


## Instructions

1.	After downloading SCRT, extract the ZIP file to a local folder.
2.	Open the extracted folder and launch SCRT by opening the index.html file. For the best experience, use Mozilla Firefox, Microsoft Edge, or Google Chrome.
3.	Select [Instructions](https://github.com/Section508Coordinators/SCRT/blob/master/Resources/SCRTTrainingManual.pdf ) to open the detailed SCRT instruction manual in accessible PDF format.
4.	Select Create Report to create a new test-results report or edit an existing report.</br>
	![Select & Load](./Resources/select_load.JPG) 
*	For first-time use, select the applicable standard template, either the TT4 or TT5 JSON file, from the Resources folder. 
*	To edit an existing report, select a valid custom JSON file that was previously created or pre-filled.
5.	Complete or update all required fields in the report. When the required information has been entered, the option to save the test results will be available.
6.	Save the report as a JSON file by selecting the Save button at the bottom of the page or using the keyboard shortcut Alt+Z. The JSON file is saved to your local device, typically in the Downloads folder. Use this file for future editing, analytics, or reporting.
7.	Select View Report to open a saved report that contains at least one valid test result. The View Report page is read-only and does not allow edits.
8.	To save a printer-friendly HTML version of the report, select the Save button at the bottom of the View Report page or use the keyboard shortcut Alt+S.
9.	Save both file formats for future reference:
*	JSON: Editable file for future updates, analytics, and reporting.
*	HTML: Read-only, user-friendly, printer-friendly version of the completed report.
